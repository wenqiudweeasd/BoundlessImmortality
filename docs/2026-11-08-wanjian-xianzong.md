# 万剑仙宗 · 微信小游戏分支玩法（本地验证版）

日期：2026-11-08。依据《武灵修仙：万剑仙宗》GDD v0.2 和对应的立项讨论记录。按“在原有基础上新增、不修改原有玩法”的要求实现：新代码全部在 `Source/BoundlessImmortality/WanJian/`，账本单独存放在 `Saved/WanJian/wanjian-local.json`，和直播版的仙途、武灵账本互不相通。

对原有文件只有两处改动：`InkUIRoot.cpp` 增加一条页面路由，`InkUIScreenHud.cpp` 在每日一签、仙道殿旁增加「万剑仙宗」入口。

## 解读与取舍

| 策划案原文 | 实现取舍 |
| --- | --- |
| 技术栈 Godot 4 + GDScript | 11-08 交接选定 UE → WASM，且要求在现有工程上新增，所以用 UE C++ 实现。第 10、19 章的 Godot 目录和脚本结构不采用，接口和数据权威的要求保留 |
| 12 种剑灵按“普通卡池 / 高稀有 / 限定”标注 | 策划案给了 72/23/4.5/0.5 四档概率，没给每把剑属于哪档。我的分配：普通＝赤炎、玄冰、惊雷、磐岳；优秀＝破甲、焚风、归潮；稀有＝续命、镇岳；传说＝星痕 0.4%、七星 0.1% |
| 临界值组队均分 | 内部 1 点＝120 单位，人数 1～4 都能整除，不需要跨击杀摊平余数 |
| 第 1～10 关人工精修 | 第 1 关血量预算为常规的 45%，线性升到第 10 关的 100%，保证新账号只用本命剑能通过第 1 关 |
| 组队与 4 人房间 | 只实现规则：掉率、数量权重、刷怪和血量倍率、临界值均分。队友由本地模拟（复制一份剑阵），没有 WSS 房间服务 |
| 失败求援 | 失败页有再次挑战、调整剑阵、邀请好友。邀请目前返回本地房间 token，不发奖励 |
| 激励广告 | 走 `IWanJianPlatform`，非微信环境由本地模拟。Shipping 构建拒绝模拟结果 |
| 装备、法宝、道具掉落 | 先记为数量（Equipment/Artifact/Consumable），具体物品表待接入 |

## 未实现

- 3D 战斗表现：目前战斗在页面内的二维竞技场显示，还没接到现有的飞剑和怪物场景。
- WSS 房间服务、服务端权威结算和账号体系。策划案要求公开版必须具备这些才能开放抽卡、广告奖励和组队加成。
- 90 秒三阶段渡劫挑战、第二灵根、更多功法和副本专属关卡。
- 微信广告、登录和分享的真实适配，要等小游戏能在手机上运行。
- 上线前的合规核对（抽奖概率公示、广告规范等）。
