# 仙途物品系统 · 四货币 · 商城 · 每日一签 · 境界突破（本地验证版）

日期：2026-11-01。范围：四种货币与 50 个设计物品、灵玉/武灵/金元三个商城、仙道殿、每日一签、专用境界突破界面与 Niagara 突破特效、渡劫时打坐不可移动，以及策划案中三个预留界面（物品来源、武灵建设、装备法宝）的表现层。**全部为本地验证**：账本写在 `Saved/XianTu/xiantu-local.json`，不接入直播 SDK、支付或服务端；界面上以“本地验证”“未接入充值”等字样标明。

## 解读与取舍

| 需求原文 | 实现取舍 |
|---|---|
| 灵玉商城在“剑途” | 项目里没有“剑途”，按“仙途”（HUD 右上“仙途”入口）实现，仙途页新增“灵玉商城”卡片 |
| 武灵商城在武灵（门派） | 武灵山门总览与“建设”页签各有入口，武灵建设页底部也可进入 |
| 仙道殿只做 UI 和商城 UI，专门兑换外观 | HUD 第二排新入口；金元商城 12 件外观（剑灵外观、头像框、称号、足下灵光），可兑换、穿戴、卸下，**只改变显示，不改变任何属性**；外观尚未挂到角色模型上 |
| 每日一签 | 策划案 11 章原写“固定轮换剑诀、不做随机吉凶”，按本次需求改为随机签运；保留“不可付费改签”。概率（需求未给，我定的）：上上签 10%、上签 35%、下下签 35%、灾 10%、凶 10% |
| 幸运 +50% / +10% | 项目原有“幸运”属性是预留字段、没有玩法效果。现在幸运作用于世界历练的“机缘”：每完成一个阶段有 20% ×（1＋幸运）概率额外获得一份下一大境界的突破辅材 |
| 灾：渡劫成功概率 −10% | 按 10 个百分点扣（50% → 40%），与助力、保底一起计算后夹在 0–100%；连败五次的“必成”在灾签当日也会被扣成 90% |
| 凶：受到伤害增加 50% | 主播受到的命中伤害与天罚雷击都 ×1.5（`FLiveAnchorBuff::DamageTaken`），自身消耗生命的效果不算 |
| 笑境界 / 避熊吉兆 | 按“小境界”“避凶吉兆”理解 |
| 大境界：核心材料＋天材地宝＋滋润灵物＋避凶吉兆 | 对应 v1.4 第 15 章的 core / treasure / essence / guard 四类，品质评分、上限与档位全按 `tables/items-v1.4` |
| 小境界需要核心材料 | 小境界沿用“修为圆满＋破境石”，破境石即小境界的核心材料；大境界改为只消耗本阶核心与所放辅材，不再扣破境石 |

## 50 个物品

全部来自 `docs/design/2026-10-21-wuling-resource-v1.4/tables/items-v1.4`：

- **40 种突破材料**：BR01–BR10 十个大境界阶段，每阶段 1 种核心材料＋每类辅材的首个物种（避凶吉兆 G01、滋润灵物 E01、天材地宝 T01）。每种分下品/中品/上品/极品四个品阶，账本键为 `MAT_BR01_C01_G2` 这样的“物种_品阶”。
- **10 个道具**：清心散、凝神香、护心符、清瘴丸、涤魂茶、归真露、太清符、问道灯、无极香、回影玉简，选的是效果在现有系统里能真实生效的十个：驱散负面、清除中毒、符箓屏障（同类取最高）、治疗、香雾/灯影演出（问道灯、无极香会让下一次突破加一层“天开”特效），回影玉简在突破记录上打标记。各自有冷却，大境界门槛按设计表。
- 另有 4 种武灵建设材料（灵纹木、青罡砖、云纹绢、阵纹砂），建了武灵后直接进公库，不进个人背包。

物品定义在 `Source/BoundlessImmortality/XianTu/XianTuCatalog.*`，并并入 `XianTuRules::Items()`，背包、奖励演出、商城和来源页共用同一份。背包里本地种子数据中与账本重复的灵石、筑基丹、功法残卷、铜钱在进入游戏后移除。

## 每日一签

HUD 右侧第二排“每日一签”，未求签时带红点。页面是一只红漆签筒：点“摇签”后签筒摇动约 1.35 秒，一支签跳出、旋转放大，随后立签揭晓（竖排签名、四字签语、两句签文、效果与剩余时间）。上上签/上签放金光，灾/凶起黑雾和裂纹。签运以主播 Buff 显示在 HUD（吉/灾/凶），持续到当日子时，驱散无效；下下签不加 Buff。

## 境界突破

新页面“境界突破”（仙途卡片、HUD 指引、角色页“突破”按钮都指向它）：

- **小境界**：修为进度、破境石数量，满足即可突破。
- **大境界**：核心材料槽（点选在 极品→下品→取下 之间切换）、避凶吉兆/滋润灵物/天材地宝槽（数量上限按阶段，点空槽放入最好的可用品阶，再点取下）、品质评分 Q 与六档品质条、分项（核心＋护道＋精华＋奇珍）、一键放入/清空/材料来源。
- **渡劫阶段**（BR04 起）：按钮变为“前往渡劫”。天劫页的检查项改为核心材料与当前方案品质；**渡劫成功才扣核心与辅材**，失败全部保留。
- **淬炼**页签：两份同品＋灵石合成高一品（灵石 = 10 × 阶段序号 × 目标品阶，按 recipes.csv）。
- **品质**页签：每阶段最高快照；品质因子 = 1 + min(10%, Σ(档位系数−1)/10)，乘到主播攻击、生命、防御上（`UCultivationSubsystem::SetAnchorQualityFactor`）。
- 突破成功时页面播放“破”字印章落下、光芒、新境界牌匾升起与品质档位文字。

## 突破特效（Niagara）

由 `Tools/SpecialSwords/special_sword_vfx.py` 生成三套水墨光效，`XianTuBreakthroughFx::Play` 在 `OnRealmAdvanced` 时挂到主播脚下（任何突破途径都会播放）：

| 系统 | 何时 | 内容 |
|---|---|---|
| `NS_SS_BreakMinor` | 小境界 | 彩色圆相、墨圈、灵气旋绕上身、星芒、地面光环 |
| `NS_SS_BreakMajor` | 大境界 | 墨色与本境界色两层八卦阵反向旋转、光柱与白芯、墨笔与光丝反向盘旋、莲花绽开（结晶起两层）、云聚云散、三道冲击波（第三道筑基后）、元神起剑阵环立、光尘上升 |
| `NS_SS_BreakAscend` | 元婴起（或问道灯/无极香期间） | 天开：自高空倾泻的宽光柱、光柱上三重光环、化神起双龙光丝盘旋、炼虚起头顶北斗、光瓣飘落、脚下云海 |

境界越高：颜色换到对应大境界的色相（练气碧玉 → 金丹金 → 化神紫 → 混元无极白金）、亮度更高、半径与光柱更大、更多层被点亮。

## 渡劫打坐

天劫准备、渡劫、对账与天罚期间，主播强制入定（`UCultivationGameplayComponent::SetTribulationMeditation`），移动输入被忽略、不能收功或攻击；结算后自动起身。

## 预留界面（方便后续接入）

- **物品来源**：按阶段看每种材料的区域副本（后续开放）、淬炼、商城、历练机缘来源与各品阶持有数，可跳转购买/淬炼/历练；道具与货币的来源和用途。
- **武灵建设**：八座建筑（武灵大殿、炼丹阁……万灵碑）各三档外观，消耗公共资材与公库建设材料，只改外观。
- **装备法宝**：四个非武器槽＋一个法宝槽的人物框、16 件装备与 12 件法宝的列表与境界锁、本地试穿与加法属性汇总（装备制作接入前不生效）。

## 测试入口

GM 面板动作（`ALiveGMOverlay::ExecuteGMAction`，验证脚本也用）：`XT_Bundle` 发放测试物资（含四货币、下一阶段各品阶材料、全部道具、公库材料）、`XT_Realm<n>` 把主播放到第 n 境且修为圆满、`XT_Fortune<k>` 指定下一签（1 上上签 … 5 凶，0 取消）、`XT_FortuneReset` 清掉今日签、`XT_Guild` 建武灵、`XT_Fx.<from>.<to>` 只播放突破特效、`XT_Do_<Verb>.<参数>` 直接执行账本指令。

验证脚本：`Tools/InkFrontend/verify_ink_economy_pie.py`（720×1280 竖屏，真实 Slate 点击，含横屏复核），输出到 `Saved/InkUI/Economy/<时间>/`。脚本会消耗和发放本地账本数据，运行前请备份 `Saved/XianTu` 与 `Saved/CultivationPrototype`。屏幕外的按钮先用 `UInkGameUIWidget::RevealTestTarget` 滚入视野再点击；`GetPlayerRealmIndex` 用于核对突破前后的境界。
