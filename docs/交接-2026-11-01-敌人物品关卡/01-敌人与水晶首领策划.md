# 敌人与水晶首领完整策划

## 1. 成长、战斗与五种敌人

用户确定：生命、攻击、防御遵循项目成长公式，攻速与移速按指定值。代码参考 `Cultivation/CultivationRules.cpp::PersonalAttributes` 的线性成长形式；不能给怪物调用观众分支（其生命/防御会归零）。

```text
r = 项目境界索引：练气一阶0、五阶4、七阶6、九阶8、筑基初期9
G(r) = 1 + r × g
H = 基础生命 × G(r)
A = 基础攻击 × G(r)
D = 基础防御 × G(r) + 装甲固定加成
V = 测试角色的无临时增益基准移动速度（cm/s）× 类型速度系数
```

`g` 读取当前成长规则，头文件默认 0.25；表中按 0.25 举例，不能硬编码截图结果。BOSS 的 3000/150/500 是 **r=0 的基础值，筑基仍乘 G(9)**，不是筑基最终属性。成长只施加一次；防御额外 75/250 加在成长之后。攻间隔、速度不随此成长倍率再次膨胀。角色速度应从实际 Movement/移动实现读，不把属性中的归一化 MoveSpeed=1 当作 1cm/s。

| ID / 名称 | 默认境界 r | 基础 H/A/D | 装甲加值 | 间隔 | 速度 | g=.25 时 H/A/D |
|---|---:|---|---:|---:|---:|---|
| EN_G01 哥布林 | 0 | 100/10/10 | 0 | 1s | 1.0V | 100/10/10 |
| EN_G02 哥布林（装甲） | 4 | 100/10/10 | 75 | .8s | .8V | 200/20/95 |
| EN_G03 红色哥布林 | 6 | 100/10/10 | 0 | .5s | 1.2V | 250/25/25 |
| EN_G04 红色哥布林（装甲） | 8 | 100/10/10 | 250 | .5s | 1.0V | 300/30/280 |
| EN_G05 哥布林首领（水晶） | 9 | 3000/150/500 | 0 | 1s | 1.0V | 9750/487.5/1625 |

普攻继续经过 `LiveCombat::Resolve`，包括境界差、防御和现有减伤上限，不用“攻击力直接扣血”绕过公式。`EnemyAttributeMultiplier` 是已有动态敌人削弱效果，不是境界成长；两者必须分开。表内是无临时效果的数值，测试固定关闭动态增益后核对，正式本地玩法仍保持旧增益兼容。此次不修改特殊剑灵原有成长或技能伤害。

普通怪最低行为：发现测试角色→追踪→范围内按间隔普攻→受击/击退→死亡。用户未指定感知范围、攻击距离、巡逻，建议先沿用现有可调默认，只加本关所需逻辑。死亡只能触发一次掉落。敌人遇墙不能无 Sweep 穿过去；复杂导航与 Behavior Tree 属后续改善，不列首周硬要求。

## 2. 水晶首领共享状态

建议建立一个本地 Encounter 状态持有：EncounterId、原始境界与属性快照、共享 MaxHP/HP、是否进入第二阶段、主体/分身引用、存活召唤物集合、召唤冷却、吸收属性、已结算标记。主体和分身是两个受击实体，使用同一个血池与阶段状态，不复制第二份生命。

基础攻击与防御计算：成长基值→吸收加值→阶段倍率→已有动态效果。第二阶段防御提高 150% 按 **×2.5**，非 ×1.5；新增 25% 减伤通过现有伤害管线应用，并与其他减伤遵循项目上限，不当作 +25 防御。当前 `ALiveMonster::ApplyHit` 把 Reduction 写死为 0，需补正式的可配置/可覆写减伤入口，不能仅在 Blueprint 改血绕开战斗公式。

### 技能 1：晶巢召令（用户规则＋实现边界）

- 召唤 5 只哥布林；每只独立等概率从 EN_G01–04 选一种，允许五只同种。
- 召唤物的 **境界覆盖为当前 BOSS 境界**；使用各类型基础属性、装甲加值与速度/攻间隔，不能保留其默认练气境界。
- CD 20s；建议开战即可首次施放，完成一次有效召唤后开始计时。CD 已好但仍有任一召唤物存活时等待，全部死亡后才允许再施放。
- “场上哥布林”建议定义为本 Encounter 的召唤物，排除首领主体/分身和其他房间怪物。主体与分身共享这份名额及 20s 冷却，**最多 5 只**，避免各自召五只变为十只；分身仍可成为本次施法者。
- 在可行走空位生成，失败位置可有限重试；记录真正生成的数量。不得因生成失败清空仍存活的召唤记录或短时间重复刷满。被友伤杀死、正常杀死均从集合移除。

### 技能 2：晶魂双生（用户规则＋防重复）

- 共享生命严格低于 50% 时触发一次；等于 50% 不触发。回血回到 50% 以上再降低不重复召唤。
- 生成一个分身；建议属性继承比例默认 100%，作为明确可配置项。分身继承普攻、技能 1 和技能 3，不能再触发技能 2。
- 主体与分身同时进入防御 ×2.5、减伤 25% 阶段；没有新血条、不回复到满血。若一次伤害已致死，优先死亡，不补生成分身。
- 任一实体受伤扣同一共享生命；共享生命归零，两实体统一停止攻击、碰撞与技能，只结算一次 BOSS 死亡和一个宝箱。
- 同一攻击实例的同一伤害段同时命中两个实体，建议只扣共享池一次；不同攻击/持续伤害下一跳正常扣血。不能按一个过宽“技能 ID”把全段持续攻击都去重。
- 吞噬等特殊死亡入口也必须接入共享死亡，不能只在 `OnDeath` 蓝图里同步隐藏另一只。

### 技能 3：碎晶灭域

用户确定：蓄力 5s，以自身为中心半径 **300cm**；敌我均受影响；伤害为自身攻击 780%＋目标已损生命 35%；击杀友军后获取其 5% 属性，不获取生命，对自己分身无效。

建议补齐以下未指定细节：

| 参数 | 建议默认 |
|---|---|
| 普通 CD / 首次可用 | 释放完成后 15s / 开战后 10s；均配置化 |
| 蓄力移动 | 站定，显示完整 5s 红色圆形预警与倒计时；不普攻、不同时召唤 |
| 命中时间 | 蓄力结束一次性判定；预警不是每帧伤害；离开圆圈可躲避 |
| 受击退 | 不设 BOSS 永久免控；被击退则中心随实体移动、预警同步移动，蓄力计时继续，不重复伤害 |
| 目标范围 | 当前房间战斗单位；排除施法者、同 Encounter 主体/分身、掉落物与门；当前剑灵若本就无独立生命，不人为增加血量 |
| 已损生命取值 | 命中前的 max(0, MaxHP−HP)，不是“本次造成伤害后”的缺血 |
| 友军吸收口径 | 建议仅吸收被本次技能确实击杀的哥布林的攻击、防御，各为其生成属性快照的5%；不复制生命、攻间隔、技能、减伤、境界与成长率 |
| 累积和继承 | 同 Encounter 本局加法累计，主体/分身共享一次，不从已吸收后的动态面板递归计算；离开/重置本局清零 |
| 分身施法 | 独立技能3计时，初始与本体错开 7.5s；仍共用召唤名额与吸收池 |

伤害建议为同一个非暴击普通伤害包：

```text
Raw = A×7.8 + LostHP×0.35
Coefficient = 7.8 + LostHP×0.35 / max(A, ε)
用 Hit.Attack=A、SkillCoefficient=Coefficient 走 LiveCombat
```

这样防御仍以 A 为攻击统计量计算，整个 Raw 都受防御、境界与减伤影响，不把 35% 缺血偷偷设为真伤。命中前快照目标集合，逐目标结算后再统一加本次友军吸收，避免先杀的友军让同一波后杀目标受到更高攻击。友军死亡不额外发普通怪掉落/经验，正常玩家击杀才按普通掉落表；BOSS 自己及分身不互相伤害、吸收或重复结算。

## 3. 三把剑灵适配与血条

统一目标接口仍为 `ALiveMonster` 及注册表；建议新增 C++ 派生敌人而不脱离注册。所有新怪物及分身均需支持三把剑的命中、死亡和击退，不能因换成骨骼模型就使技能失效。

| 剑灵（代码显示名） | 当前证据 | 新模块要求 |
|---|---|---|
| 无机态那 | `LiveSpecialSwordKinds.cpp` 砸地调用 `ApplyPush(Spot,450,.35)` | 保留原距离与时长；不穿门/墙，不在击退时反向追踪瞬移 |
| 七星光芒剑 | 同文件 Radiance 投射物 Knockback=500，`LiveSwordProjectile.cpp` 调用 ApplyPush | 保留穿透与逐目标击退；用户“光茫”按当前代码名“光芒”统一 |
| 驱煞神刃 | 当前双影归一大招对范围目标 `DealDamage`，未见 ApplyPush | 建议仅大招释放命中存活敌人后追加从冲击中心向外 450cm/.35s；不额外给每次普通攻击击退，列为本次新增适配而非已有行为 |

击退默认最后一次有效击退覆盖当前速度，沿用现有行为；不叠加无上限速度。近中心方向为零时使用确定的兜底方向。死亡后不再移动，撞墙停止。血条方案优先扩展已有 HUD：普通怪显示名称、境界、当前/最大生命；BOSS 屏幕顶部只一条共享条，分身头顶标“分身·共享生命”，数值来自同一个模型。可用 WBP/WidgetComponent 做新展示，但不得同时保留重叠旧条。
