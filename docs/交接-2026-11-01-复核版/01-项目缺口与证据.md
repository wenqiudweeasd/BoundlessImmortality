# 当前功能缺口与源码证据

> 历史研究；其中直播派工已撤销。当前任务以 [本地玩法交接](../交接-2026-11-01-敌人物品关卡/00-交接说明.md) 为准，不让接手者开发或测试抖音相关功能。

## 调研边界

基准为 2026-11-01、`main / a486e36`。本次进行了源码、配置、插件、工具目录及已有验证说明的静态核对。以下结论不是编译、PIE 或抖音实播测试结果；“本地已实现”也不代表正式账号、支付、网络和审核已完成。

项目同时存在 `Cultivation` 成长系统、`XianTu` 本地玩法账本和 `Wuling` Python 本机原型服务。不要把一套系统的函数或测试作为另一套系统的完成证据。当前仙途页面以 `UXianTuSubsystem` 为重要业务入口，主 UI 是 Slate，由 `UInkGameUIWidget` 承载，不适合一周内重做成 Blueprint UI。
